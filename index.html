Tenant verbinden

Microsoft Graph autorisieren

Verbinden Sie TenantScope mit Ihrem Microsoft-365-Tenant. Die Inventur arbeitet mit delegiertem Zugriff und den von Ihnen gewählten Prüfbereichen.

Noch nicht gespeichert

Microsoft Graph enthält keine Vertragspreise. CSV-Format: sku;preisProMonat, z. B. SPE_E3;35,70. Die Datei bleibt im Browser.

Klarnamen in Nutzungsreports optional Die Inventur funktioniert auch mit anonymisierten Kennungen. Optional kann ein Administrator Klarnamen tenantweit aktivieren; Microsoft protokolliert die Änderung und die Übernahme kann einige Minuten dauern.

Tenant-Daten vollständig?Im nächsten Schritt wählen Sie den Prüfumfang und starten die Live-Inventur.

Was wird benötigt?
  1. Eine Single-Tenant-App in Microsoft Entra.
  2. Die angezeigte URI als Single-Page-App.
  3. Delegierte Microsoft-Graph-Leserechte.
  4. Tenant-ID und Application-ID – kein Client-Secret.

    Nutzungshinweis und Haftungsausschluss

    TenantScope erstellt eine automatisierte Momentaufnahme aus den Daten, die Microsoft Graph zum Prüfzeitpunkt bereitstellt. Ergebnisse können unvollständig, verzögert oder aufgrund fehlender Rechte und Lizenzen nicht auswertbar sein.

    • Verwenden Sie die Anwendung nur für Tenants, zu deren Prüfung Sie berechtigt sind.
    • Prüfen Sie Befunde und Empfehlungen fachlich, bevor Sie Konfigurationen, Zugriffe oder Lizenzen ändern.
    • TenantScope ersetzt keine Rechts-, Datenschutz-, Sicherheits- oder Lizenzberatung. Die Verantwortung für Entscheidungen und Änderungen bleibt bei Ihnen.
    • Die Inventur ist grundsätzlich lesend. Nur die gesondert gekennzeichnete Option „Tenantweit Klarnamen aktivieren“ ändert eine Microsoft-365-Reporteinstellung.

    Informationen zur Verarbeitung finden Sie im Datenschutz. Anbieterangaben stehen im Impressum.
